# Recommended Website Page Structure

## Main Pages
- /
- /about
- /contact
- /get-quote
- /services
- /airport-transfers
- /city-transfers
- /intercity-transfers
- /border-transfers
- /umrah-taxi-service
- /hajj-transport-service
- /ziyarat-taxi-service

## City Pages
Create dynamic pages under:

`/taxi-service/[city]`

Examples:
- /taxi-service/riyadh
- /taxi-service/jeddah
- /taxi-service/makkah
- /taxi-service/madinah
- /taxi-service/dammam
- /taxi-service/khobar
- /taxi-service/jubail
- /taxi-service/taif
- /taxi-service/abha
- /taxi-service/tabuk
- /taxi-service/alula
- /taxi-service/yanbu
- /taxi-service/hail
- /taxi-service/najran
- /taxi-service/jazan

## Airport Pages
Create dynamic pages under:

`/airport-transfer/[airport]`

Examples:
- /airport-transfer/riyadh-airport
- /airport-transfer/jeddah-airport
- /airport-transfer/madinah-airport
- /airport-transfer/dammam-airport
- /airport-transfer/taif-airport
- /airport-transfer/abha-airport
- /airport-transfer/tabuk-airport
- /airport-transfer/yanbu-airport

## Route Pages
Create dynamic pages under:

`/routes/[from]-to-[to]`

Examples:
- /routes/jeddah-to-makkah
- /routes/makkah-to-madinah
- /routes/riyadh-to-dammam
- /routes/madinah-to-alula
- /routes/jeddah-to-taif
- /routes/khobar-to-bahrain
- /routes/riyadh-to-qatar-border

## Border Pages
Create dynamic pages under:

`/border-transfers/[border]`

Examples:
- /border-transfers/bahrain-causeway
- /border-transfers/qatar-border
- /border-transfers/uae-border
- /border-transfers/kuwait-border
- /border-transfers/jordan-border
