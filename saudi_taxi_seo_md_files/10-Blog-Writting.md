# SEO Blog Structure Requirements

Every blog created for the Saudi Taxi website must follow this structure:

## SEO Fields

* SEO Title (50–60 characters)
* Meta Description (140–160 characters)
* SEO URL Slug
* Focus Keyword
* Secondary Keywords
* Open Graph Title
* Open Graph Description
* Featured Image Alt Text

## Blog Structure

### H1

Main blog title containing the focus keyword.

### Introduction

* 150–250 words
* Mention focus keyword naturally
* Explain what the article covers

### Table of Contents

Auto-generated from headings.

### H2 Sections

Minimum 5–8 H2 sections.

### H3 Sections

Use supporting H3s under relevant H2s.

### Internal Links

Link to:

* Homepage
* Get Quote page
* Relevant service pages
* Relevant city pages
* Relevant route pages

### External Links

Link only to high-authority sources where relevant.

### CTA Section

Include:

* Get Quote button
* WhatsApp CTA
* Call Now CTA

### FAQ Section

Minimum 5 FAQs.
Add FAQ Schema.

### Conclusion

150–200 words.

## Content Requirements

* Minimum 1,500–2,500 words
* Original content
* Human-readable
* EEAT optimized
* No keyword stuffing
* Use semantic keywords
* Use lists and tables where helpful

## Schema Requirements

Generate:

* Article Schema
* Breadcrumb Schema
* FAQ Schema

## Dynamic Database Fields

Each blog should store:

* title
* slug
* excerpt
* content
* metaTitle
* metaDescription
* focusKeyword
* featuredImage
* featuredImageAlt
* author
* category
* tags
* publishedAt
* readingTime
* schemaJson
* status
* createdAt
* updatedAt
